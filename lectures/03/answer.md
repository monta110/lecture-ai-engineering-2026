## 演習

- 第1回（素のLLM）とエージェントの回答の違い：
  - 質問「AIE2026の講座の宿題にある「3レベル」とは何ですか？」で比べた
  - 第1回（app.ask）：講座の資料を持っていないため「一般論」と断ったうえで、レベル1 基礎・入門／レベル2 応用・実践／レベル3 発展・高度、という一般的な分け方を推測で答えた。講座の定義（基礎・実装・発展）とはずれていて、出力も 517 トークンと長かった
  - 第3回（app.agent）：「基礎（講義内容の確認）・実装（自分でコードを書く）・発展（調査や試行）の3つで、どれか1つに取り組めば完了、原則採点なし」と答えた。data/glossary.json の homework-levels の定義とほぼ同じ内容で、回答の最後に「第1回」と関係する回も示した
  - 違いの理由：素の LLM は講座のことを知らないので、もっともらしい一般論で埋める。エージェントは答える前に用語集を検索するので、根拠のある答えになる
- `--trace` で見えたツール呼び出し（ツール名と引数）：
  - 「LoRA とQLoRAの違いは？」では `search_glossary({'query': 'LoRA'})` と `search_glossary({'query': 'QLoRA'})` の2回
  - docstring の「query には調べたい用語を1つだけ入れる」のとおり、2語が別々に検索された。回答は用語集の定義に沿っていて、最後に「関係する回：第2回」が付いた（INSTRUCTIONS のとおり）
- 1つの質問での LLM 呼び出し回数（`requests`）：
  - requests=2, tool_calls=2（1回目で2件の検索をまとめて依頼し、2回目で回答を作成）。input_tokens=1196, output_tokens=178
- 追加したツールと、docstring に書いた説明：
  - `make_quiz(lecture: int) -> str`。指定した回の用語から1つを選び、問題と答えを JSON で返す。該当する用語がない回では、エラーにせず「用語集にありません」と返す
  - docstring：「指定した回の用語から 1つを選び、確認問題と答えを返す。「第2回の確認問題を出して」のように、復習用の問題を求められたときに使う。」
  - 確認：`--list-tools` に表示された。「第2回の内容から確認問題を 1問出して」で `make_quiz({'lecture': 2})` が呼ばれた（requests=2, tool_calls=1）。pytest は 17 passed
  - 気づき：make_quiz は問題と答えの両方を返したが、モデルは答えを伏せて「考えてみてください」と返した。INSTRUCTIONS の「答えそのものは書かず、ヒントで導く」を確認問題にも当てはめたと考えられる。ツールの結果がそのまま利用者に届くのではなく、最後はモデルが取捨選択している。また、出題の依頼では search_glossary は呼ばれなかった
